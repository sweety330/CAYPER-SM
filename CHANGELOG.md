# Changelog

## 1.0.0

- Reworked the project into a complete first playable neighborhood and cyber-cafe simulation loop.
- Added a wider Egyptian-inspired neighborhood with park, home, grocery shop, job board and street traffic props.
- Added NPC wandering and dialogue, computer use, cafe management, employee hiring and business accounting.
- Added inventory, consumables, repair kits, player needs, daily jobs and claimable quests.
- Added three save slots with persistent player, economy, inventory, quest, cafe and audio data.
- Added generated sound effects and cafe ambience.
- Fixed the duplicate time-system setup by using one authoritative game clock.
- Removed unused legacy controller scripts and corrected the main scene entry point.
